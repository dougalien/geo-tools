Finite Deformable Geometry

A web book, plain-language guide and interactive model exploring a finite, deformable universe: redshift, gravity, shape and boundary transitions.

Open Finite Deformable Geometry (opens in a new tab)

Get started

  1. Start on the Home page for the big picture and the schematic of the model.
  2. Read the Guidebook for the same path in plain language before the technical chapters.
  3. Work through Chapters 1 to 4, from infinity and measurement through supernovae, the cosmic microwave background, galaxies and boundary behavior.
  4. Keep Registers open alongside: it summarizes the key symbols used throughout.
  5. Ask FDG AI short questions about the model, equations and figures. It answers from the web book in plain language.

Tips

  • The interactive companion app lets you explore the model visually and compare observational relationships.
  • Cite it as: Allen, D. (2026). “A Finite Universe”. Zenodo. doi:10.5281/zenodo.20492474.
  • The Appendix and References hold the calculations and sources behind each chapter.
