App guide

TraceCode

Analyze x-y lab signals from gas chromatography (GC), X-ray diffraction (XRD) and SEM/EDS: clean up baselines, smooth, find peaks and look at frequencies.

Open TraceCode (opens in a new tab)

Get started

  1. Upload a CSV, TXT or Excel file, or pick one from Or try a sample dataset.
  2. Set the Dataset Type (GC, XRD, SEM/EDS or generic) and check the X and Y columns.
  3. Work through the tabs: Raw Trace, Prepared Signal (baseline and smoothing), Peaks and FFT.
  4. Use Compare and Interpret to match peaks with reference minerals or elements.
  5. Report gathers results you can download as CSV.

Tips

  • Start with a sample dataset to see what each step does.
  • AI help is optional. The core analysis never needs it.
  • The full TraceCode user manual (PDF) covers every setting.
  • If nobody has used the app for a while it goes to sleep. Click the button that says the app is asleep (“Yes, get this app back up”) and give it up to a minute.
